How I work

A simple loop

  1. Explore

    Start with a useful question.

    Follow curiosity, read broadly, and reduce the problem to something testable.

  2. Build

    Turn the idea into an experiment.

    Prototype with the smallest practical stack, then learn from real behavior.

  3. Document

    Leave a trail for the next iteration.

    Keep code and notes clear enough to revisit, reuse, and share.
